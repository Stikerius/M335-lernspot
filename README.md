# LernSpots

Schulprojekt Modul 335 «Mobile-Applikation realisieren» (BZZ), 2er-Gruppe.

LernSpots ist eine App zum Erfassen, Bewerten und Wiederfinden von Lernorten wie Bibliothek, Café, Schule oder Draussen. Die Daten bleiben lokal auf dem Gerät, es gibt keinen Server und kein Login. Die App ist mit Expo in JavaScript gebaut und läuft in Expo Go.

## Startanleitung

```bash
npm install
npx expo start
```

Danach den QR-Code mit dem Handy scannen und die App in Expo Go öffnen.

## Git-Regeln

- Pro Feature ein eigener Branch, zum Beispiel `feature/karte` oder `feature/formular`.
- Merge per Pull Request.
- Kleine Commits mit klarer Nachricht.
- Nach jeder Änderung prüfen, dass `npx expo start` ohne Fehler bündelt.
